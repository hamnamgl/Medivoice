# Demo Video Script

## 2-3 Minute Flow

1. Problem setup
- "Community health workers often have no doctor, no internet, and no decision support."
- Show MediVoice on phone or browser.

2. Offline setup proof
- Show local Ollama or Kaggle demo notebook.
- State clearly whether this is `demo mode` or `true offline mode`.

3. Multilingual consultation
- Urdu or Roman Urdu fever example
- Hausa maternal danger example
- Show one-question-at-a-time flow
- Highlight final verdict format

4. Referral and dosage grounding
- Ask for a drug dose
- Ask for the nearest clinic in Islamabad or Nairobi
- Mention that responses come from local offline data packs

5. Image triage
- Show a wound or rash image example
- Explain that MediVoice describes visible signs and gives one safe action

6. Close
- Mention privacy, low-connectivity deployment, and local data overlays
- End with global CHW impact statement
