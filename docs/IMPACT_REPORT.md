# Impact Report

## Intended Users

MediVoice is designed for community health workers operating in low-resource environments, especially where:

- doctors are not immediately available
- connectivity is unreliable
- workers are overloaded
- language barriers reduce access to digital tools

## Why It Matters

Many frontline workers are forced to make referral or home-care decisions with limited support. MediVoice aims to reduce guesswork by giving:

- one-question-at-a-time guidance
- danger-sign awareness
- structured next-step recommendations
- local-only data handling

## Accessibility Goals

- mobile-friendly PWA access
- multilingual interaction
- voice-first paths
- simple action-oriented outputs

## Privacy and Equity

The offline-first model helps with:

- patient privacy
- low operating cost
- broader reach in low-connectivity settings
- less dependence on cloud subscriptions

## Current Impact Readiness

The project is now stronger as a demo and prototype because it has:

- local inference
- bundled data plus custom local overlay support
- referral and dosage routing
- a reproducible Kaggle demonstration path

## Remaining Impact Work

To support real deployments at scale, the project still needs:

- wider sourced data coverage
- stronger clinical review of bundled starter packs
- localized organization onboarding
- pilot validation with supervised field users
