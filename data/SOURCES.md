# Data Sources

This file tracks what MediVoice currently bundles, what now has an official-source snapshot, and what is still starter or placeholder content.

## Snapshot Files Imported From Official Public Sources

These files are metadata snapshots generated by `scripts/data/fetch_global_sources.py` and saved under `data/source_snapshots/`.

- `data/source_snapshots/who_essential_medicines_2025.json`
  - Status: `official-source snapshot`
  - Source: WHO Model List of Essential Medicines, 24th list
  - URL: `https://www.who.int/publications/i/item/B09474`

- `data/source_snapshots/who_imci_2014.json`
  - Status: `official-source snapshot`
  - Source: WHO IMCI chart booklet
  - URL: `https://apo.who.int/publications/i/item/9789241506823`

- `data/source_snapshots/official_referral_registries.json`
  - Status: `official-source catalog snapshot`
  - Sources:
    - Kenya Master Health Facility Registry: `https://kmhfr.health.go.ke/public/about`
    - Nigeria Health Facility Registry: `https://hfr.health.gov.ng/about-us`
    - Pakistan NHSRC downloads: `https://www.nhsrc.gov.pk/download`

These snapshot files are not full raw exports. They are provenance anchors and planning inputs for future structured normalization.

## Recommended Source Strategy

For stronger deployment quality:

1. keep official-source snapshots under `data/source_snapshots/`
2. normalize selected content into runtime JSON used by the app
3. clearly mark each runtime file as `placeholder`, `curated`, `starter`, or `verified`
4. let organizations add local overlays in `data/custom/`

## Overlay Model

MediVoice uses:

1. built-in offline core data
2. optional organization-specific overlays in `data/custom/`

This lets an NGO, district program, or clinic network add local facilities and approved medicine variations without editing the core bundled files directly.
